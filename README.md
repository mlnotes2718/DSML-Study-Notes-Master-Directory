#### 3. Python Development Environment
When using Python for software development, we need a contained environment to manage the software version effectively. In Python, there are many environment management tools. The most popular and the oldest is `pip`. `Pip` is the package installer that install and manage version conflict between software libraries. However, a lot of people have migrated to `uv`. This new package installer is written in Rust and it is significantly faster. It also uses the same library as `pip` which is `PyPI`. In the machine learning community, `conda` is the popular package installer. Although it is slower, it did what `pip` or `uv` cannot do, it also manages non-Python native dependencies such as C++, CUDA and R more effectively. As a beginner, I would recommend start with `conda` and you may consider `uv` for future deployment if CUDA is not required.
